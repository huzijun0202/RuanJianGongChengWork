# 实验四 状态机实现（Python）

本目录用 Python 3.12 标准库实现了实验四的三个状态机模型，与实验报告中的 B1/B2/B3 状态图一一对应。

| 模块 | 状态图 | 说明 |
| --- | --- | --- |
| `b1_water_tank.py` | B1 恒温水箱 | 待机 / 加热 / 维修 / 休眠 四个状态，20° 低温启动加热、100° 断电、烧坏维修、23:00 休眠、7:00 恢复 |
| `b2_control_panel.py` | B2 SafeHome 控制面板 | 读取键入字符 / 验证密码 / 系统功能选择 / 锁定 四个状态，4 位密码、错误 3 次锁定 120 秒 |
| `b3_string_extractor.py` | B3 源文件字符串提取 | 普通文本 / 字符串内 / 转义 三个状态 + 终止状态，处理双引号与反斜杠转义 |
| `demo.py` | 演示程序 | 依次运行三个状态机，打印状态迁移日志并做断言检查 |

## 运行

```bash
python demo.py
```

## 设计要点

- 每个状态机都维护 `state`（当前状态）与 `history`（迁移日志），状态名与状态图中的状态名一致。
- 状态图中的每条迁移对应实现中的一个方法或判断分支，守卫条件写成 `if` 条件，动作用方法体实现，便于与模型逐条对照。
- 边界情况在实现中显式处理：B2 的失败计数与锁定超时、B3 的输入结束时字符串未闭合等。
